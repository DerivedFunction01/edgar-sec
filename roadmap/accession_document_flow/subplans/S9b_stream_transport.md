## Owner and status

- Owning stage in [S9](S9_acquisition.md): bounded HTTP body transfer.
- Status: streaming/staging design only; current broker transport returns body bytes.
- Depends on: [S9a work orders](S9a_target_adapter.md), S4 broker lifecycle.

## Current tracked-code audit (2026-10-08)

- **Status: not implemented.** The current HTTP client and broker still materialize complete bodies as bytes; there is no staged-body handle or stream-to-managed-file API in the tracked transport.
- **Evidence:** [`infra/sec_http/client.py`](../../../edgar_sec/infra/sec_http/client.py) consumes `response.content`, and [`infra/broker/sec_broker.py`](../../../edgar_sec/infra/broker/sec_broker.py) sends and receives the complete payload in its framed response. [`document_storage_disposition.md`](../document_storage_disposition.md) states that this broker needs a streaming-to-stage extension.
- **Next step:** extend the broker/HTTP seam to stream bounded chunks into owner-generated staging paths and return metadata/digests only; add offline tests for size abort, redirects, cleanup, and body-free IPC.

## Objective

Transfer multi-megabyte filing bodies without buffering them in the broker's parent process or returning payload bytes over process IPC.

## Models

```python
@dataclass(frozen=True, slots=True)
class StagedBodyRef:
    staging_id: str
    path: Path
    origin: Literal["http_response", "bundle_child"]
    source_url: str | None
    final_url: str | None
    body_sha256: str
    body_size: int
    content_type: str | None
    content_encoding: str | None
    derived_from_sha256: str | None

@dataclass(frozen=True, slots=True)
class StreamFailure:
    target_id: str
    code: Literal[
        "http_not_found", "http_error", "timeout", "transport_error",
        "response_too_large", "unsafe_redirect", "empty_body",
    ]
    retryable: bool
    detail: str

StreamResult = StagedBodyRef | StreamFailure
```

## Interface and flow

```python
stream_to_stage(
    work: AcquisitionWork,
    *,
    staging: ManagedStaging,
    max_body_bytes: int,
) -> StreamResult
```

The SEC broker owns the HTTP session, retry policy, rate limiter, and failure ledger. It reads response chunks and writes them to a generated file under the configured transient directory while incrementally computing SHA-256 and decoded body size. `Content-Length` is an early rejection hint; the streamed byte count is the enforcement check. Apply the byte budget after HTTP content decoding so compressed responses cannot expand past the memory/disk budget.

On a limit breach, stop reading, close the response, delete the partial file, and return `response_too_large`; never return a truncated body. Redirect destinations are checked against the SEC host policy before bytes are accepted. The final URL and content headers are recorded for provenance.

The transport returns a small `StagedBodyRef`, not bytes. A child process opens the managed path for extraction and returns only result metadata and digests. Path names are generated by the staging owner, not from accession, URL, or filing data. Staged files are removed on all error paths and after S10 consumes them unless S9d commits a fixture copy.

Worker concurrency is derived with `derive_resources()` and `auto_worker_count()`; each child receives at most one active body/extraction task and the submitted queue is bounded. The maximum body size and worker memory estimate are settings/measurements, not duplicated numeric limits in S9 code.

## Tests

- A fake streaming transport feeds chunks across the byte limit and verifies early abort, partial-file removal, and typed failure.
- Missing `Content-Length` cannot bypass the accumulated-size limit; a compressed body is bounded after decoding.
- Successful transfer has a byte-identical digest, correct final URL, and no payload bytes in the broker result or worker-to-coordinator IPC.
- Redirects outside the allowed SEC hosts fail before accepting the body.
- In-flight body count and worker count remain within the derived resource budget.
- Staging cleanup handles success, transport failure, timeout, process failure, and cancellation.

## Acceptance criteria

Payload size is bounded during transfer, process handoff is by managed path and metadata, and normal acquisition does not materialize an entire response in the broker parent or coordinator. Fixture capture is the only path that retains source bodies after the downstream run.
