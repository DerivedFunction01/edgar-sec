# docgen

Layer 6. CLI reflection and Markdown sentinel synchronization.

## Purpose

Keep generated documentation aligned with CLI and artifact-path contracts.
`docgen` inspects `ArgumentParser` and `paths.py` definitions to update
Markdown sentinels; `path_tree` renders artifact trees from those definitions.

## Contracts

- **Path-tree resolution is static**: Path expressions and imported constants
  are read from source ASTs; path modules are not imported to build trees.
- **Deterministic formatting**: Autogenerated sentinels produce byte-identical
  Markdown across repeated runs.
- **Offline execution**: Tooling performs zero network I/O.

## Deliberate gaps

- **Does not generate semantic prose**: `## Purpose`, `## Contracts`, and
  `## Deliberate gaps` remain strictly human-authored.
