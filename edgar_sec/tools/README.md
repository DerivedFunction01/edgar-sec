# `edgar_sec.tools` — generation and verification tooling

Layer 6. Code generation, CLI reflection, and documentation sentinel synchronization.

## Purpose

Eliminate documentation drift by introspecting `ArgumentParser` instances,
paths dataclasses, and AST docstrings, synchronizing Markdown sentinels in place.

## Contracts

- **Strict downward dependencies**: Layer 6 may import from any lower layer (0-5),
  but no lower layer may import from `tools`.
- **Deterministic formatting**: Autogenerated sentinels produce byte-identical
  Markdown tables across repeated runs.
- **Offline execution**: Tooling performs zero network I/O.

## Deliberate gaps

- **Does not generate semantic prose**: `## Purpose`, `## Contracts`, and
  `## Deliberate gaps` remain strictly human-authored.
