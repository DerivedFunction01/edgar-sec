# `edgar_sec.tools` — generation and verification tooling

Layer 6. Code generation, CLI reflection, documentation sentinel synchronization,
pytest worker calibration, fixture gathering, and XBRL seeding and evaluation.

## Purpose

Keep generated documentation aligned with CLI and artifact-path contracts,
select pytest worker counts from measurements scoped to the requested tests,
plan and score fixture candidates from the filing catalog, and seed and
evaluate grounded XBRL populations.

## Packages

- **docgen**: CLI reflection and Markdown sentinel synchronization.
- **workers**: Pytest worker calibration and timing-profile storage.
- **fixtures**: Fixture-gathering planning and candidate scoring.
- **xbrl_discovery**: XBRL linkbase seeding and taxonomy archive construction.
- **xbrl_eval**: XBRL census, screening, and benchmark verification.

## Contracts

- **Strict downward dependencies**: Layer 6 may import from any lower layer (0-5),
  but no lower layer may import from `tools`.
- **Path-tree resolution is static**: Path expressions and imported constants are
  read from source ASTs; path modules are not imported to build artifact trees.
- **Deterministic formatting**: Autogenerated sentinels produce byte-identical
  Markdown across repeated runs.
- **Aggregate profiles are independent**: Child-scope optima seed parent searches
  but never replace direct measurements of the parent's combined test selection.
- **Case timings are incremental**: Unchanged test observations survive inventory
  updates; failed, interrupted, and pruned probes are not valid timing samples.
- **Baseline pruning requires coverage**: `n=0` or `n=2` is skipped only when
  observed per-case call work is sufficient to reject it against a direct result.
- **One pytest invocation per probe**: Mixed selections retain their original
  selectors and shared session-fixture behavior.
- **Offline generation and calibration**: `docgen` and `workers` perform zero network I/O. The gathering tools are the exception by design: `fixtures` scoring and `xbrl_discovery` seeding fetch from SEC and taxonomy hosts.

## Deliberate gaps

- **Does not generate semantic prose**: `## Purpose`, `## Contracts`, and
  `## Deliberate gaps` remain strictly human-authored.
- **No per-file worker allocation**: A mixed selection uses one global worker
  count; independently scheduling files at different counts is deferred to avoid
  splitting a pytest session.
